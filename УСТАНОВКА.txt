УСТАНОВКА ПРИЛОЖЕНИЯ НА АНДРОИД-ПЛАНШЕТ

Это установочное веб-приложение (PWA): ставится на главный экран как обычное
приложение, открывается без адресной строки, работает без интернета.
Данные (чертежи, маркеры, фото, ТЗ) хранятся на самом устройстве.

1. Разместите содержимое этой папки на любом сайте с HTTPS
   (подойдёт бесплатный хостинг: GitHub Pages, Netlify, Cloudflare Pages,
   либо свой сервер). Нужны все файлы:
   index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
2. На планшете откройте адрес в Chrome.
3. Меню ⋮ -> «Установить приложение» (или кнопка «Установить приложение»
   вверху страницы). Значок появится на экране.
4. Один раз откройте приложение при включённом интернете - после этого оно
   работает офлайн.

Перенос данных между компьютером и планшетом:
«Резервная копия (JSON)» на одном устройстве -> «Загрузить копию» на другом.

Без хостинга: можно просто скопировать index.html на планшет и открыть в Chrome
(как файл). Работает так же, но без установки на экран и без офлайн-кэша.
